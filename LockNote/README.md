# ЛокЗаметки v8.0
Обновлённое Android-приложение для заметок на экране блокировки, задач с датой и временем, таймеров выполнения и напоминаний.

**Новое:** приоритеты, категории, поиск, повторы дел, статистика, перенос срока +1 день и создание копии задачи.

Исходники: `LockNote/sources.tar.bz2.base64`. Их разворачивает GitHub Actions при сборке. Архив создан из локально проверенного проекта v8. Подробная документация находится в `README.md` внутри распакованного архива.

**APK:** [GitHub Actions](https://github.com/rumt55555-boop/StroyObem/actions/workflows/build-locknote-apk.yml) → Build LockNote v8 APK → Artifacts → `LockNote-v8-APK`.

**Важно:** debug APK может быть подписан новым ключом при очередной сборке. Если обновление поверх предыдущей установки не принимается, **сначала экспортируйте резервную копию JSON**. Удаление приложения удаляет его локальные данные.
