# LockNote / ЛокЗаметки v6

Действующее Android-приложение для заметок на экране блокировки и задач со сроками. Сохраняет прежний applicationId и старые заметки при обновлении совместимо подписанным APK.

**Новое:** задачи с датой и временем, выполнением, напоминаниями и отображением ближайших на блокировке. Поддерживаются резервные копии JSON v5/v6.

GitHub Actions: [Build LockNote v6 APK](https://github.com/rumt55555-boop/StroyObem/actions/workflows/build-locknote-apk.yml). По завершении в артефактах сборки ищите **LockNote-v6-APK**.

Исходники разворачиваются из файла `sources.tar.bz2.base64` командой `base64 -d sources.tar.bz2.base64 | tar -xj`. Проверьте файл `README.md` после распаковки для подробностей. Старый workflow StroyObem не изменён.

Важно: GitHub Actions создает debug APK; для обновления поверх ранее установленного приложения подписи должны совпадать. Если подпись другая, сначала экспортируйте JSON, затем переустановите приложение и импортируйте копию.
