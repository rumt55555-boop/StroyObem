# ЛокЗаметки / LockNote v7

Android-приложение с заметками на блокировке, списком дел с датами и **таймерами выполнения**.

Для каждого дела задаётся таймер 1–1440 минут. Кнопки ▶ Старт, ⏸ Пауза и ↺ Сброс доступны в карточке задачи. После закрытия приложения отсчёт сохраняется. Когда время вышло, приложение может показать системное уведомление (доставка зависит от Android и режима энергосбережения); задача автоматически **не** отмечается выполненной. На обоях отображается статус таймера, но не секундный отсчёт.

Исходники v7 находятся в `sources.tar.bz2.base64`. Они автоматически разворачиваются при сборке через `.github/workflows/build-locknote-apk.yml`. При желании: `base64 -d sources.tar.bz2.base64 | tar -xj`.

**Сборка:** GitHub → Actions → Build LockNote v7 APK → Run workflow; артефакт `LockNote-v7-APK`.

JSON-резервные копии v5/v6 поддерживаются. Новый формат v7 сохраняет состояние таймеров. Совместимая установка поверх старой версии сохраняет данные, но debug APK разных запусков могут быть подписаны разными ключами. При конфликте подписей сначала экспортируйте данные старой версии.

Проект `StroyObem` и его собственный workflow не изменены.
