# ЛокЗаметки (LockNote) v5

Android-приложение, отображающее заметки на обоях экрана блокировки, с редактором, чек-листами, виджетом и экспортом JSON.

Исходники хранятся в `sources.tar.bz2.base64`. Workflow `.github/workflows/build-locknote-apk.yml` автоматически разворачивает их и собирает APK при изменениях в папке `LockNote/`.

**Сборка**: GitHub → Actions → Build LockNote v5 APK → Run workflow; результат в Artifacts → LockNote-v5-APK.

Исходный проект можно также скачать как ZIP в чате. Подпись debug APK предназначена для тестовой установки, не для публикации в Google Play.
